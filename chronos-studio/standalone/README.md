# Chronos Studio standalone build

This directory holds the desktop launcher, the offline wheelhouse build inputs
and the `.deb` packaging script. The installable package itself is written to
the workspace root as `chronos-studio-standalone_0.1.0_amd64.deb`.

See `../STANDALONE.md` for installation, requirements, privacy notes and the
features that are intentionally degraded to keep the package within the
workspace size budget.
